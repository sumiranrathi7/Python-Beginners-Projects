# Python Beginner Projects

A collection of practical Python projects built to strengthen programming fundamentals, logical thinking, and problem-solving skills.

## Projects

### 1. Simple Calculator
Performs basic arithmetic operations based on user input.

### 2. Student Grade Calculator
Calculates total marks, percentage, and grade based on student marks.

### 3. Number Guessing Game
Generates a random number and allows the user to guess it with multiple attempts.

### 4. Quiz Application
Presents questions with multiple options and calculates the user's score.

### 5. To-Do List
Allows users to add, view, update, and remove tasks.

## Concepts Covered

- Variables and Data Types
- Input and Output
- Conditional Statements
- Loops
- Functions
- Lists and Dictionaries
- Exception Handling
- Basic Object-Oriented Programming
